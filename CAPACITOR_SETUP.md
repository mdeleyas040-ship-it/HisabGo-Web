# Hisab Go — Capacitor Android setup

This branch prepares the existing React + TypeScript + Vite app for Capacitor. It does not yet prove that Android builds or Google sign-in work; run the steps below locally and test before merging.

## Prerequisites

- Node.js 22 or a version supported by the installed Vite and Capacitor releases
- Android Studio with an Android SDK installed
- Git working tree clean before starting

## Install and build

```powershell
npm install
npm run lint
npm run build
```

## Create the Android platform once

The `android/` folder is generated by Capacitor and should be committed to Git after creation. Run this only if the folder does not already exist:

```powershell
npx cap add android
```

Then build and sync web assets:

```powershell
npm run android:build:web
npx cap open android
```

In Android Studio, wait for Gradle sync, then run the app on an emulator or connected device.

## Important identity note

The current `capacitor.config.ts` uses `com.amarhisab.hisabgo` as a proposed application ID. If an existing Android app already uses a different package ID, change this value before creating the Android platform. Do not change a published app's application ID if you intend to update that same app.

## Firebase status

The existing code already has Firebase configuration, Google popup authentication, localStorage persistence, and a manual Cloud Firestore sync flow. This branch does not yet claim that account isolation, cross-device conflict handling, or native Google sign-in is fixed. Those need dedicated changes and end-to-end tests before production use.

## Before merging

1. Verify `npm run lint` and `npm run build` locally.
2. Test two separate Firebase accounts in separate browser profiles.
3. Confirm account A cannot see or upload account B's local data.
4. Test initial sync, upload, download, and concurrent edits on two devices.
5. Test Google sign-in on the actual Android app; `signInWithPopup` may not work as expected inside a WebView.
6. Verify Firestore rules in the Firebase Emulator or Rules Simulator.
7. Commit the generated lockfile and Android project after verifying the build.
